# 🎮 Who wants to be a millionaire | Parcial 2 (Pygame)

Who Wants to Be a Millionaire is a desktop quiz game inspired by the classic TV show.  
The project simulates a full playable experience with multiple-choice questions, difficulty levels and a graphical interface built with Pygame.

## 🧠 Features

- 🎮 Interactive graphical interface using Pygame
- ❓ Multiple-choice question system
- 📊 Difficulty selection system (Easy / Medium / Hard / Extreme)
- 🏆 Prize ladder / scoring system
- 📁 External question management using CSV file
- 🧩 Modular architecture (separation of logic and UI)
- 💾 File handling for data persistence
- 🔁 Replay functionality
- 🎯 Fully playable desktop game

---

## 🛠️ Tech Stack

- Python 🐍
- Pygame 🎮
- CSV file handling 📁
- Object-oriented programming (OOP principles)
